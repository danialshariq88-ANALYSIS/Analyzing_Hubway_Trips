# Analyzing_Hubway_Trips
Analyzed Hubway bike-sharing trip data using Python, Pandas, SQL, and Jupyter Notebook. Explored trip duration, user types, gender, bike usage, popular routes, and station activity to identify patterns and insights from the data.

## Dataset
The dataset (hubway.db, ~130 MB) is hosted on Google Drive due to GitHub's file size limit.
